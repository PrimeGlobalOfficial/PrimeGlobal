# Prime Global — Commercial License Listing

## Product

**Prime Global — Ready-to-Deploy Online Jobs Platform**

Prime Global is a responsive online-jobs and remote-work information website designed as a foundation for a larger online-work marketplace.

## What a buyer gets

- Complete website source code
- Responsive desktop and mobile layouts
- Online-work and remote-job content structure
- Job category pages
- Kenya-focused online-work content
- AI training, data annotation, data entry, transcription and translation sections
- FAQ and informational pages
- SEO-ready page structure and metadata
- Sitemap support
- GitHub Pages deployment structure
- Documentation and commercial licensing framework

## Current state

The current product is a **static website**, not a finished SaaS marketplace. It does not currently include production-grade authentication, employer dashboards, a database-backed job marketplace, or a production payment system.

That is deliberate: the platform is structured as a strong front end that can be extended with a backend.

## Expansion opportunity

A buyer can extend Prime Global with:

- worker accounts and profiles;
- employer accounts;
- job posting and applications;
- saved jobs and application tracking;
- job moderation and verification;
- notifications;
- payments or rewards;
- administrator tools;
- analytics; and
- a custom domain and backend service.

## License options

### Standard commercial license

For one business deployment, with modification rights for that deployment. Ownership of the underlying Prime Global intellectual property remains with the owner.

### Extended commercial license

For buyers needing broader deployment or client-service rights. Exact permissions are agreed in writing.

### Exclusive acquisition

Available only by separate negotiation. An exclusive transaction would require a separate written agreement covering intellectual-property rights, branding, repository access, existing deployments, and retained rights.

## Important buyer note

The GitHub repository is currently public because it supports the live GitHub Pages website. Buyers should therefore understand that this is a **commercial license opportunity**, not a claim that the public repository is an exclusive unpublished codebase.

For an exclusive transaction, the repository and public deployment would need to be handled separately as part of the negotiated agreement.

## Suggested sales process

1. Buyer reviews the live demo and public documentation.
2. Buyer requests the license type and any customization requirements.
3. Scope and price are agreed in writing.
4. Payment is made through an agreed secure payment/escrow method.
5. After payment clears, the licensed package or agreed repository access is delivered.
6. Optional deployment/customization support is handled according to the agreement.

## Positioning

Prime Global should be marketed as a **ready-made online-jobs website/platform foundation**, not as a fully operational marketplace with users, employers, revenue, or payment infrastructure that does not yet exist.
