# Security Policy

## Reporting a security issue

Please do not publish passwords, API keys, payment credentials, private user information, or other sensitive security details in GitHub issues.

If you discover a security problem in Prime Global, contact the project owner privately with:

- the affected page or file;
- a short description of the issue;
- steps needed to reproduce it; and
- any relevant screenshots or evidence that does not contain private information.

## Repository safety

Before any commercial delivery, the repository should be checked for:

- exposed secrets or credentials;
- personal information;
- unnecessary development files;
- third-party assets without appropriate rights; and
- broken or misleading links.

The commercial package should contain only material that Prime Global is permitted to license.
