# Prime Global

**Prime Global is a ready-to-deploy online-jobs and remote-work information platform.**

Live website: https://primeglobalofficial.github.io/PrimeGlobal/

## What is included

Prime Global is a responsive, static web platform designed to help people discover online work and remote opportunities. The project includes structured pages covering areas such as:

- Online jobs and remote work
- AI training
- Data annotation
- Data entry
- Transcription
- Translation
- Online work opportunities in Kenya
- Job-search guidance and safety information
- Frequently asked questions
- About and support information

The project is intentionally structured so that a future backend can be added for accounts, applications, employer tools, payments/rewards, saved jobs and other marketplace functionality.

## Current technology

- HTML5
- CSS3
- JavaScript
- Responsive/mobile-first layouts
- GitHub Pages deployment
- SEO metadata and sitemap support

## Product direction

Prime Global is being developed toward a full online-work marketplace. Planned backend capabilities include:

1. Worker registration and profiles
2. Employer accounts
3. Job posting and applications
4. Saved jobs and application tracking
5. Moderation and verification tools
6. Payment/reward functionality
7. Analytics and administration

## Important status note

The current version is a **static website**. It does not yet provide a production backend, real user authentication, or a production payment system. Those capabilities are planned for a later development phase.
