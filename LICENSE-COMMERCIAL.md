Prime Global is being offered as a commercial software product. This document describes the intended commercial licensing framework for customers who purchase a license from the owner.

This repository is not distributed under an open-source license. The public GitHub repository exists in connection with the public website deployment. A person viewing or forking the public repository does not receive a commercial license from Prime Global.

GitHub's platform terms may allow viewing and forking of public repositories; that platform access does not constitute a separate commercial license from Prime Global.

## Commercial license types

### Standard License

A Standard License is intended for one customer/business deployment.

Unless the signed purchase agreement says otherwise, the Standard License permits the buyer to:

- deploy the purchased version for the buyer's own business;
- modify the code for that deployment;
- connect the project to the buyer's own hosting and backend services; and
- use the project as part of the buyer's own online-work website.

The Standard License does not transfer ownership of Prime Global's underlying intellectual property.

### Extended License

An Extended License may provide broader commercial rights, such as additional deployments, client work, or broader redistribution rights. The exact permissions must be stated in the purchase agreement.

### Exclusive transfer

An exclusive transfer is a separate transaction and is **not** included in a normal license. If an exclusive transfer is agreed, the parties should sign a separate written agreement identifying exactly what rights are transferred, what rights are retained, and what happens to the public GitHub repository and existing deployments.

## Restrictions

Unless expressly permitted in a signed agreement, a licensee may not:

- claim ownership of the original Prime Global code or brand;
- resell the source code as a competing template or code package;
- redistribute the source code to multiple unrelated customers;
- sublicense Prime Global to third parties; or
- represent Prime Global as an official service operated by the licensee.

## Third-party materials

Prime Global may contain or reference third-party libraries, services, fonts, icons, images, links, or other materials. Those materials remain subject to their own terms and licenses. A Prime Global commercial license does not transfer rights that Prime Global itself does not own.

## Payment and delivery

A commercial license becomes effective only after the agreed payment has cleared and the buyer has accepted the applicable license terms. Source-code delivery, private repository access, deployment assistance, or other deliverables should be provided according to the purchase agreement.

This document is a product licensing framework, not a substitute for jurisdiction-specific legal advice. For a high-value or exclusive transaction, the final agreement should be reviewed by a qualified legal professional.
